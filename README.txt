# PlaNora - Concert & Event Management System

Mini project for NetBeans using HTML, CSS, JavaScript, Jakarta Servlets, JDBC and MySQL.

## Setup
1. Create/import the Maven project in NetBeans.
2. Open database/planora.sql in MySQL and run it.
3. Open DBconnection.java and replace YOUR_MYSQL_PASSWORD with your MySQL root password.
4. Use JDK 17+ and Apache Tomcat 10.1+.
5. Clean and Build.
6. Run the project.
